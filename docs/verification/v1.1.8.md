# v1.1.8 acceptance record

Status: released and installed, 28 November 2026. The owner's in-game check is still to
come.

## Scope

Ported selected fixes and UX improvements from upstream releases v1.2.0–v1.3.0 (head
`ffb784a`), keeping the fork English-first with no telemetry, no Tencent hosts, and no
cloud switches:

- **Detail panel background toggle:** Added a bottom-right **Background** button on the
  in-game details panel cycling between **Transparent**, **Semi-transparent**, and
  **Opaque**, persisted in `config.json` (`overlay_bg`).
- **In-game champion search focus:** Recorded the foreground window before entering the
  search box so typing (including the autocomplete popup) keeps the overlay visible when
  opened from League without painting over unrelated apps.
- **Weapon of Destiny (`3081`) build styles:** Added support for patch 16.23's
  `destiny_style_v1` rows, mapping Chinese style tags to English (`AP`, `AD`, `Tank`,
  `Support`) and omitting unsplit prefixes.
- **Win32 64-bit handle & I/O hardening:** Added explicit `HWND`/`BOOL` ctypes
  signatures for `user32`, checked `ClientToScreen` failures, switched `Settings.save()`
  to fsync'd atomic writes with Windows rename retries, added rollback and `.old` backup
  recovery for dataset swaps, and clamped blended rank win rates to `[0, 1]`.
- **Autostart sync:** Synced the **Start with Windows** state between the tray menu and
  Settings, surfacing errors if toggling from the tray fails.
